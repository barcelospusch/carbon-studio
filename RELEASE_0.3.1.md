# Carbon Studio 0.3.1

Esta versão atualiza a identidade visual do Carbon Studio e simplifica o trabalho com imagens dentro dos projetos.

- Novo logotipo na interface e nos ícones do aplicativo Windows.
- Novos ícones na árvore para criar pastas, importar arquivos e pastas, renomear, mover e excluir imagens.
- Prévia de imagem ao passar o mouse e visualizador com ações para renomear, mover ou enviar à Lixeira.
- Guia de sintaxe em um botão compacto e aviso quando houver uma release estável mais recente no GitHub.
- Botões de preferências e de cancelamento da compilação alinhados ao visual da interface.

Se você vem da versão 0.2.0, esta atualização também inclui [as novidades da versão 0.3.0](https://github.com/barcelospusch/carbon-studio/blob/v0.3.1/RELEASE_0.3.0.md), como Mermaid integrado, currículos, paginação configurável, novos recursos de matemática e navegação pelos títulos do documento.

## Downloads para Windows x64

- `Carbon-Studio-0.3.1-x64-Setup.exe` para instalar.
- `Carbon-Studio-0.3.1-x64-Portable.exe` para executar diretamente.
