# Ícones internos do Monaco (opcionais)

Estes 12 desenhos cobrem os widgets de busca/substituição e folding importados pelo Studio. Os mesmos chevrons atendem aos estados automáticos e manuais. São distintos da biblioteca de SVGs da interface e exigirão adaptação de CSS na integração.

- `chevron-right.svg` — Expandir busca e regiões recolhidas
- `chevron-down.svg` — Recolher busca e regiões expandidas
- `close.svg` — Fechar busca
- `selection.svg` — Buscar na seleção
- `replace.svg` — Substituir ocorrência
- `replace-all.svg` — Substituir todas
- `arrow-up.svg` — Ocorrência anterior
- `arrow-down.svg` — Próxima ocorrência
- `case-sensitive.svg` — Diferenciar maiúsculas/minúsculas
- `whole-word.svg` — Palavra inteira
- `regex.svg` — Expressão regular
- `preserve-case.svg` — Preservar maiúsculas/minúsculas

Menus e outros widgets internos podem acrescentar ícones da biblioteca Codicons conforme comandos do Monaco são abertos; não devem ser confundidos com os 35 slots do aplicativo.
