# Começar

1. Abra uma pasta com documentos `.cb` ou escolha um template na tela inicial.
2. Selecione o documento no explorador à esquerda.
3. Use a barra sobre o editor para inserir elementos Carbon. Clique em um título da estrutura para navegar até sua linha.
4. Pressione **Ctrl+Enter** para compilar, **Ctrl+S** para salvar e **Ctrl+Shift+E** para exportar o PDF.

Em Preferências, escolha tema, papel padrão, autor e instituição. O tema altera o editor e a interface. Os dados de autoria são usados nos novos templates.

A primeira compilação LaTeX pode precisar de internet para baixar fontes e pacotes TeX. A distribuição inclui o motor PDF e o renderizador Mermaid.
